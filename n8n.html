use cases

不是炫技，是把日常杂活收进流程里。

这里展示的是虚拟但常见的自动化场景。真正接项目时，我会按数据源、触发频率、失败补偿和通知对象单独拆流程。

scenario 01

信息采集与整理

把网页、表单和 API 返回的数据统一成可用格式，自动去重、归档和标记。适合资料收集、日报汇总、项目线索整理。

scenario 02

AI 内容处理

让模型负责摘要、分类、提取行动项，人只检查结果，不再复制粘贴。

scenario 03

消息通知与同步

把关键更新推送到 QQ、邮件或项目工具，并把过程写进日志方便追踪。

重复的流程，就该交给流程。

这是一个展示页，不连接真实 n8n 实例。真正的工作流可以按你的数据源、Agent 能力和通知渠道重新编排。
